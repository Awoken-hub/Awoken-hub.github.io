Unity 射线检测原理

检测三维空间中射线与平面碰撞的过程：

  1. 屏幕坐标转换成从摄像机的近平面上发射到远平面的一条射线 Ray
  2. 射线 Ray 与平面 Panel 求交点

射线与平面求交点

属性

Ray

  • m_Origin ：原点
  • m_Direction ：方向
    Panel
  • m_Normal 法线
  • m_Distance 距离（从原点到该平面的距离）

射线与平面的交点检测接口

  • dot ：射线方向与平面法线求点积，得到两向量夹角θ的cos值
  • ndot
    • 三维空间中的平面可以表示为 \vec{n}·\vec{x} + d = 0 ，其中
      • n⃗\vec{n}​n​⃗​​ 表示平面的法向量
      • x⃗\vec{x}​x​⃗​​ 表示平面上任意一点
      • d 表示平面到原点的距离
    • 三维空间中的射线可以表示为 r(t)=o⃗+td⃗r(t) = \vec{o} + t\vec{d}r(t)=​o​⃗​​+t​d​⃗​​ ，其中
      • o⃗\vec{o}​o​⃗​​ 表示射线的原点
      • d⃗\vec{d}​d​⃗​​ 表示射线的方向
      • t 为参数，大于0时射线才存在
    • 将以上两式联立，得到 \vec{n}·(\vec{o} + t\vec{d}) + d = 0，解得 t = \frac{-d - \vec{n} · \vec{o}}{\vec{n} · \vec{d}} ，ndot 即该式的分子部分
  • enter 即上式中的参数 t ，只有大于0时才表示射线存在，即射线与平面有交点。
