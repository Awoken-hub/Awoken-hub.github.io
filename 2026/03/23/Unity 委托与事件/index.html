Unity 委托与事件

名词解释

  1. 委托：指定格式的函数的模板，可以放入各种格式相符（参数的数量和类型、返回值的类型相同）的函数的引用。
  2. 事件：特殊的的委托

委托类型

1. 自定义委托

2. Unity 内置泛型委托

2.1 Action：无返回值

Action 可以支持 0 - 16 个参数

2.2 Func：有返回值

可以添加参数，最后一个代表返回值类型。

使用方法

1. 事件

事件的使用就是在普通的委托变量声明时加上字段 event 。在其它类中，使用带 event 字段的委托不可以直接使用 = 进行赋值（声明添加 event 字段后，直接赋值操作的权限变为 private），只能使用 += 。

2. 多播委托

一个委托对象可以挂载多个方法，按顺序执行。

3. 空引用检查

.?Invoke() ：在确保委托/事件不为空时才执行调用。

注意：MonoBehaviour:Invode 是用于字符串延时调用的方法，与委托的安全调用是不同的概念。
