手工材料与成品库存管理文档说明

管理文档简介

本管理文档系统使用 Markdown 语法 ，基于 Obsidian 文档建立，旨在为手作人们提供轻量的材料与成品库存管理方案。应用场景包括：库存管理、销售统计、定制订单记录、思路笔记。

使用教程

  1. 将文档在 Obsidian 中打开。
  2. Ctrl + P调出命令面板，选择命令 Templater: Create new note from template，再选择你想要依据的模板，即可创建新的指定格式的文档。四种模板文档的详细介绍见下文。

模板文件

  • 储存模板文件，目前预设了四种模板文件。
    • 材料模板
    • 成品模板
    • 活动模板
    • 定制订单模板

成品模板

  • 增加库存按钮功能

    • 单击后弹出**增加库存数量：**输入框
    • 输入正整数，根据成品文档中记录的材料清单与输入的增加库存数扣除对应数量的材料库存
    • 注：材料库存为0时依然可以添加库存
    • 存在 #bug

  • 材料成本与可产出数量自动计算表格

    • 根据材料清单与对应材料文档的记录，可以自动计算出该款成品的材料成本与当前材料库存还可以制作的成品数量。
    • 显示的表格分为材料明细与汇总两部分。
    • 注意，这里的“当前库存可制作数量”是一个估计值，多个成品使用同种材料的情况不会被考虑进来。

活动模板

  • locked字段
    • 用于标记本次活动是否结束，勾选后货物清单与营业额动态表格会隐藏，防止改动与误触。
  • 货物清单与营业额
    • 自动读取当前的成品文件夹内的成品文档，显示在表格中。
    • 参与栏表示该成品是否参与本次活动，默认勾选，取消勾选后会隐藏该栏，存在#bug。
    • 操作栏的按钮售出+1，点击按钮后会记录该商品的出售数+1，扣除对应的库存并计入当次活动的总销售额。
  • 导出销售记录按钮
    • 将上述动态表格导出为静态的 markdown 表格，并记录导出时间。
    • 该功能用于在活动结束后，导出销售记录。动态表格中的数据由于是动态的，在活动结束后，库存等信息依旧会实时更新，为了避免对已经结束的活动记录数据造成干扰，需要在结束后就导出记录并上锁。

工具

  • 导入材料订单
    • 将UTF-8 CSV格式的文件导入并读取为材料文档，点击后需要输入csv文件的路径。
    • 这里的csv文件使用的是淘宝导出的订单表格，订单csv表格表头与材料文档字段对应关系如下：
      • 商品名称 - name
      • 型号款式 - 颜色
      • 店铺名称 - 购买渠道
      • 商品数量 - stock
      • 商品金额 - price，存在#bug
    • 注意
      • 这里创建的材料文档不是按模板创建的逻辑，而是将新建的材料文档的格式写在了Scripts/importOrders.js的函数内。
      • 该功能只能初步导入，需要人工手动修改、校对。例如，一份10颗的珠子导入文档后的单价price实际上是10颗珠子的总价。
